# Филворд «Ценности большой страны»

Веб-игра на чистом HTML/CSS/JS, без сборки и зависимостей. Адаптирована под ПК, планшет и смартфон.

## Структура

- `index.html` — разметка всех экранов (меню, игра, история, об игре)
- `style.css` — стили и адаптивность
- `app.js` — игровой движок, навигация, таймер, localStorage
- `grid-data.js` — сетка 15×15 и пути всех 17 слов (сгенерировано и провалидировано офлайн-скриптом)
- `values-data.js` — тексты описаний ценностей для страницы «Об игре»

## Локальный запуск

Открыть `index.html` напрямую в браузере нельзя из-за особенностей загрузки файлов — нужен локальный сервер:

```bash
cd filword
python3 -m http.server 8000
```

Затем открыть `http://localhost:8000` в браузере.

## Публикация на GitHub Pages

1. Создать репозиторий на GitHub, загрузить туда все 5 файлов из этой папки (в корень репозитория).
2. Зайти в **Settings → Pages**.
3. В разделе **Source** выбрать ветку `main` и папку `/ (root)`.
4. Сохранить — через 1–2 минуты игра будет доступна по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

## Механика игры

- Слово собирается протягиванием пальца/курсора по буквам **только вправо и вниз** (с любым числом поворотов, зигзагом), диагонали и движение назад запрещены.
- Отпускание — фиксация попытки: если слово есть в списке, оно подсвечивается зелёным и остаётся навсегда; если нет — короткая красная вспышка и клетки сбрасываются (буквы не исчезают).
- Ведётся таймер и счётчик найденных слов (из 17).
- После завершения поля — экран с итогами; если результат лучше всех предыдущих завершённых игр — показывается пометка «Новый рекорд».
- История игр и рекорд хранятся в `localStorage` браузера — данные привязаны к конкретному устройству/браузеру.

## Если нужно поменять список слов или размер поля

Сетка 15×15 подобрана и проверена под конкретные 17 слов правилом «только вправо/вниз». При изменении списка слов сетку нужно перегенерировать заново (текущий файл `grid-data.js` нельзя просто отредактировать вручную — буквы и пути жёстко связаны).
